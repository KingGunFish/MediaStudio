Media Studio 隐私政策

政策版本：v1

生效日期：2026 年 11 月 20 日

一句话概括：Media Studio 是一款纯本地的视频 / 图片处理工具。 所有处理都在您的设备上完成，本应用不收集任何个人信息、不申请任何系统权限、 不接入任何第三方 SDK，也不会联网传输您的任何数据。

一、适用范围与主体信息

本隐私政策适用于「Media Studio」（下称「本应用」）在 HarmonyOS PC / 2in1 设备上提供的全部功能， 包括视频转 GIF、GIF 抠图、视频裁剪、图片转黑白、图片裁剪与图标生成功能。

  • 运营主体：demonshir
  • 联系邮箱：demonshir@qq.com
  • 适用范围：仅限本应用在本机运行的场景，不含任何在线服务。

二、我们如何收集和使用个人信息

本应用不收集个人信息。具体而言，本应用：

  • 不要求您注册或登录，没有账号体系，不收集手机号、邮箱、用户名等标识信息；
  • 不读取设备标识（如 OAID / 广告标识）、IMEI、系统序列号等设备唯一标识；
  • 不收集您的位置信息，不读取通讯录、日历、短信、通话记录、相册以外的系统数据；
  • 不收集您的剪贴板内容、不采集麦克风或摄像头音视频、不获取传感器数据；
  • 不收集崩溃日志、行为埋点、点击事件等任何用于统计分析的数据。

本应用仅在您主动使用功能时，对您亲手选定的那一个文件进行处理： 文件选择器由系统提供，本应用只获得该文件的临时读取授权，读取后立即复制到应用沙箱， 处理完成后再写出结果文件。整个过程不需要您提供任何额外信息。

三、我们申请的权限

本应用不申请任何系统权限。安装清单中不包含任何 requestPermissions 条目， 因此不会向系统申请网络、存储、相机、麦克风、位置、通讯录等任何权限， 也不会弹出任何权限申请对话框。

权限是否申请用途
网络访问（INTERNET）否本应用不含任何联网逻辑
文件读写（媒体库 / 外部存储）否只读写应用沙箱目录，由系统文件选择器授予单文件访问
相机 / 麦克风否不涉及
位置 / 通讯录 / 日历 / 电话否不涉及
通知 / 后台任务 / 设备标识否不涉及

说明：应用内展示的隐私政策页面通过本地内置的静态网页渲染， 文件随安装包一并分发，不需要网络权限。

四、第三方 SDK 与第三方组件

本应用未集成任何第三方 SDK，也没有接入任何广告、统计、推送、 登录、支付或社交分享 SDK，不存在第三方 SDK 收集个人信息的情形。

本应用随包分发的唯一第三方组件是 FFmpeg（LGPL v3 授权的动态库）， 它以进程内库的方式被调用，只在本进程内完成音视频解码与编码， 不包含任何网络请求、设备标识读取或数据上传逻辑。 应用源码以 MIT 协议开源。

五、我们如何存储和保护个人信息

由于本应用不收集个人信息，因此不存在个人信息的存储问题。

本应用在设备上仅保存以下两类本地数据：

  • 您选择的素材与处理结果：位于应用沙箱目录（/data/storage/el2/base/haps/entry/files/）， 由本应用在您主动选择文件时写入，页面会显示完整路径供您取用。
  • 隐私同意记录：一条不含个人信息的标记，记录您同意的隐私政策版本号， 用于在后续启动时跳过重复弹窗。

这些数据全部保存在您的设备本地，应用不会将其上传、同步或备份到任何服务器。 卸载本应用会连同沙箱数据一并清除；您也可以随时在文件管理器中手动删除上述文件。

六、我们如何传输您的数据

本应用不进行任何网络传输。本应用不含网络请求代码、不含服务器地址、 不含数据上报逻辑，所有数据处理与结果输出均在本机完成。

七、我们如何共享、转让、公开披露个人信息

本应用不收集个人信息，因此不存在共享、转让或公开披露个人信息的情形。 本应用也不会将您的文件内容提供给任何第三方。

八、Cookie 与本地存储

本应用内的隐私政策页面是一个随安装包分发的本地静态网页， 不设置任何 Cookie、不使用 localStorage / IndexedDB 等浏览器存储。 应用自身仅使用一条如上所述的隐私同意记录。

九、我们如何处理未成年人的个人信息

本应用不收集任何个人信息，因此不处理未成年人的个人信息。 本应用不面向未成年人提供专门的服务内容。

十、您对个人信息的权利

本应用不收集个人信息，所以不存在查阅、复制、更正、删除、限制使用、拒绝同意 等针对个人信息的处理活动。但为保障您的自主决定权，本应用提供以下与隐私直接相关的操作：

  • 查看隐私政策：随时可在「设置 → 数据和隐私」中查看本政策全文，无需联网。
  • 撤回同意：在「设置 → 数据和隐私 → 撤回隐私同意」中撤回。 撤回后应用会回到首次启动状态，需要重新同意后方可继续使用。
  • 删除本地数据：通过「设置 → 数据和隐私」中的入口删除应用保存的素材与结果文件， 或直接卸载应用。
  • 投诉与咨询：如对本政策或应用的处理方式有疑问，可发送邮件至 demonshir@qq.com，我们将在收到后尽快答复。

十一、本政策的更新

本政策版本号会随内容变更同步调整。当隐私政策内容发生实质性变更时， 本应用会在下次启动时重新向您展示隐私声明并征求同意； 版本号记录在应用沙箱内，仅用于判断是否需要重新征求同意。
